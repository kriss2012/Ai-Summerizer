How to Run the AI Text SummarizerThis project consists of a simple web frontend (summarizer.html) and a Python backend (app.py) that performs the text analysis. To use it, you need to run the backend server first.PrerequisitesPython: Make sure you have Python (version 3.6 or higher) installed on your system.pip: Python's package installer, which usually comes with Python.Step 1: Set Up the Backend EnvironmentOpen your terminal or command prompt and follow these steps to install the necessary Python libraries.Install Flask & Flask-CORS:Flask is the web framework, and Flask-CORS is needed to allow the frontend to communicate with the backend.pip install Flask flask-cors
Install spaCy:spaCy is a powerful library for Natural Language Processing (NLP), which we use for the summarization logic.pip install spacy
Download the English Language Model for spaCy:spaCy needs a pre-trained model to understand English grammar and vocabulary.python -m spacy download en_core_web_sm
Step 2: Run the Backend ServerNavigate to the directory where you saved app.py using the cd command.Run the following command in your terminal:python app.py
If everything is set up correctly, you will see output like this, indicating that the server is running:* Serving Flask app 'app'
* Running on [http://127.0.0.1:5000](http://127.0.0.1:5000)
Keep this terminal window open. The server needs to be running for the summarizer to work.Step 3: Use the FrontendOpen the summarizer.html file in your web browser (like Chrome, Firefox, or Edge).Paste a long piece of text into the "Your Text" box.Click the "Summarize Text" button.The frontend will send the text to your local backend server, which will process it and send back the summary to be displayed.TroubleshootingError: [Errno 2] No such file or directoryIf you see an error like can't open file 'app.py': [Errno 2] No such file or directory after running the python app.py command, it means your terminal is not in the same folder where you saved the app.py file.Solution:Check your files: Before running the command, check which files are in your current folder.On Windows Command Prompt or PowerShell, type dir and press Enter.On macOS or Linux, type ls and press Enter.Verify app.py is there: Look at the list of files printed by the command. You must see app.py in that list.Change Directory (cd): If you don't see app.py, you are in the wrong folder. Use the cd command to navigate to the correct location. For example, if your file is on the Desktop, you might use: cd Desktop.Once you can see app.py in the file list, run python app.py again.Enjoy your new projects!
